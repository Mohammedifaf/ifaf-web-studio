# Ifaf Web Studio: Portfolio Website

Portfolio website for **Ifaf Web Studio**: fast, mobile-first websites for tour companies, travel agencies, hotels and local businesses, in **English and Arabic**.

🔗 **Live:** https://ifaf-studio-v6.vercel.app

## Features
- Single-page site in plain HTML, CSS and JavaScript (no framework, no build step)
- **English / Arabic switch** with full right-to-left (RTL) layout, remembered per visitor (`?lang=ar` also works)
- Portfolio of 9 live client websites with desktop and mobile screenshots
- Hover previews, smooth scroll and responsive layout for phones, tablets and desktop
- Contact form that opens a pre-filled **WhatsApp** message

## Client work shown
76adventure.com · gulfpridellc.com · mushtaqahmedgoa.com · indianscapital.com · islandresort.in · goldenriveria.com · ambguesthouse.com · eastwesttravelsmanipal.com · eazyridecab.com

## Run locally
```bash
python3 -m http.server 8000
```
Then open http://localhost:8000
